# ตรวจความตรงของ VFX กับไอคอน Lv50

อ้างอิงภาพที่ UI โหลดจริงจาก `public/icons/skills-v4/skill-{id}.png` และคำอธิบายใน `src/config/classes.json` เปิดดูภาพทั้งหกก่อนกำหนดการแก้ไข ไม่เปลี่ยนไอคอนหรือคำอธิบายเพื่อให้ตรงกับ VFX

คำอธิบายทุกสกิลคือ `Deals ranked area damage to nearby enemies.` ผลจริงเป็นโจมตีพื้นที่ ไม่ใช่ฮีลหรือบัฟ ตามชื่อเดิม ตรวจผลโจมตี MP และ cooldown ผ่านการเล่นจริง

| สกิล | สิ่งที่แก้ตามภาพอ้างอิง |
| --- | --- |
| swordsman-5 | ปรับปีกคมดาบเป็นลมเขียว/ขาว |
| swordsman-b-5 | เพิ่มโล่ทองและเศษหินอำพันให้ป้อม |
| mage-5 | คงดอกบัวหลายชั้น เพิ่มสีชมพู/ขาวให้เด่น |
| mage-b-5 | คงซุ้มพฤกษา เพิ่มโล่ใบไม้เขียวและประกายเหลือง |
| archer-5 | ปรับเป็นใบเขียว ดอกขาว และลูกศรทอง |
| archer-b-5 | ปรับวงเล็งเป็นม่วง และเพิ่มลูกศรพลังเข้าศูนย์กลาง |

รูปทรงหลัก Lv50 ยังใหญ่กว่า Lv40 และรัศมีคลื่นตกแต่ง 9.2 เทียบกับ 7.8 หน่วยเดิม การตรวจรับรอบหลังแก้บันทึกใน `validation.json` และ `REVIEW.md`
