# เพิ่มเวลาสกิลเป็นสามเท่า

ตามคำขอผู้เล่น เพิ่มเวลาร่ายจริงและช่วงคืนท่าที่ล็อกสกิลถัดไปเป็น 3 เท่าจากรุ่น e7ed5ec โดยใช้ตัวช่วยเวลาเดียวกันใน simulation และภาพท่าทาง ช่วงคืนท่าเดิม 0.372–0.48 วินาทีเป็น 1.116–1.44 วินาที ส่วนสกิลที่มี cast ใช้เวลาเดิมคูณสาม ทั้ง remaining และ total ของแถบร่าย

สกิลที่ไม่มีเวลาร่ายยังออกผลทันที แต่ต้องรอช่วงคืนท่าสามเท่าก่อนใช้สกิลถัดไป กฎเดียวกันใช้กับการกดเอง ออโต้ และ authoritative server คง cooldown รายสกิล MP ดาเมจ และเวลาโจมตีปกติเดิม

ภาพ anticipation และ preview รวมถึงการคาดการณ์แถบร่ายฝั่ง Realtime ใช้เวลาใหม่เพื่อให้สอดคล้องกับเซิร์ฟเวอร์ ไม่เปลี่ยน schema เซฟหรือ protocol

ผลตรวจรับและ deployment บันทึกใน artifacts/skill-timing-3x โดย browser ใช้ Chromium/SwiftShader ตรวจพฤติกรรม ไม่ใช่ FPS เครื่องผู้เล่น

Build ผ่าน และตรวจ 58 รายการผ่านบน runtime ที่หยุดแก้: simulation/authority/rank/choreography/API/realtime 55, realtime prediction 1, browser 2 รายการ มือถือวัดช่วงก่อนเริ่มสกิลที่สองได้ 1.1581 วินาที เทียบขั้นต่ำใหม่ 1.116 วินาที ไม่มี page error
