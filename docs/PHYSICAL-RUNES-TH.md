# รูนแยกชิ้นและผลต่อการคราฟ

รูนหนึ่งอันใช้ช่องกระเป๋าหนึ่งช่อง มี ID ของตัวเองและจำนวน 1 เสมอ รูนชนิด/rarity เดียวกันไม่รวมกอง ค่าโบนัส สูตรคราฟ อัตราดรอป และการฝังสองช่องต่างชนิดยังเหมือนเดิม

## วิธีใช้งาน

- Forge → Craft → Runes → Convert: เลือกผลลัพธ์ แล้วเลือกรูนจริง 4 ชิ้นต่างชนิดและ rarity เดียวกัน ผลลัพธ์ใช้ชนิดเดียวกับหนึ่งในวัตถุดิบได้
- Upgrade: เลือกรูนจริง 2 ชิ้นชนิด/rarity เดียวกัน เพื่อรับหนึ่งชิ้นระดับถัดไป สูงสุด Legend
- Forge → Runes: เลือกอุปกรณ์ ช่อง และรูนจริงที่จะฝัง สามารถถอดฟรีหรือเปลี่ยนแล้วรับรูนเดิมคืน
- กริดมีหน้าถัดไปและป้าย Copy เพื่อแยกชิ้นซ้ำ การคราฟ/อัปเกรด/ฝังส่ง ID ชิ้นที่เลือกให้เซิร์ฟเวอร์ตรวจเจ้าของ
- ซื้อขายและแลกเปลี่ยนรูนใหม่ครั้งละหนึ่งชิ้น

## เซฟเก่าและกระเป๋าเต็ม

Save รุ่น 12 / itemRevision 4 แยกกองรูนเก่าทั้งหมดเป็นชิ้น เก็บ ID ของชิ้นเดิมที่ไม่ซ้ำไว้ ไม่เปลี่ยนข้อมูลอุปกรณ์ ค่าสถานะ ราคา หรือโบนัสรูน

กระเป๋าเพิ่มเป็น 240 ช่อง (5 หน้า × 48 ช่อง) หากการแยกกองทำให้เกิน ส่วนเกินอยู่ในรายการรอรับ `runeOverflow` ในเซฟ กด Claim into bag ใน Bag หรือแท็บ Runes เมื่อมีช่องว่าง ระบบรับเท่าที่ว่าง ส่วนที่เหลืออยู่ในเซฟจนกว่าจะรับ ไม่ใช้ช่องดรอปบนพื้น

การคราฟนับช่องหลังใช้วัตถุดิบ: กระเป๋าเต็มยังผสม 4 → 1 หรืออัปเกรด 2 → 1 ได้ การเปลี่ยนรูนใช้หนึ่งชิ้นในกระเป๋าก่อนคืนรูนเดิม จึงทำได้แม้กระเป๋าเต็ม แต่การถอดอย่างเดียวต้องมีช่องว่าง

รายการตลาดเก่าที่ขายรูนหลายชิ้นรักษาจำนวนและราคารวมเดิม แสดงเป็น Legacy rune bundle ผู้ซื้อมีช่องสำหรับทั้งชุดจึงซื้อได้ การยกเลิกรายการเก่าคืนชิ้นที่ใส่กระเป๋าได้และเก็บส่วนเกินในรายการรอรับ ข้อเสนอแลกเปลี่ยนที่อ้างกองเก่าถูกล้างให้เลือกชิ้นใหม่ โดยไม่ยึดรูนของผู้เล่น

คำสั่งจากไคลเอนต์เก่าที่อ้างชนิด/rarity ยังแปลงเป็นชิ้นที่เป็นเจ้าของอย่างปลอดภัย ไคลเอนต์ใหม่ใช้ ID จริง ตรวจคำสั่งซ้ำไม่ให้กินหรือคืนรูนซ้ำ

## การตรวจรับ

Build ผ่าน และตรวจ 63 รายการไม่ซ้ำบน runtime สุดท้าย: 57 รายการกติกา/เซฟ/เศรษฐกิจ และ 6 รายการ browser/realtime รวมตรวจหน้าคราฟมือถือซ้ำหลังเพิ่มข้อยืนยันการพอดีจอ

หลักฐานอยู่ใน artifacts/physical-runes: หน้าคราฟ desktop, คราฟและฝังมือถือ 360×740, รับรายการรอรับ desktop สภาพแวดล้อม browser เป็น Chromium/SwiftShader ใช้ตรวจความถูกต้องและการจัดวาง ไม่ใช่ผล FPS เครื่องผู้เล่น
