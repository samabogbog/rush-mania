# กระเป๋าและการย่อยอุปกรณ์

## จำนวนสถานะรองที่สุ่มใหม่

| Rarity | จำนวนสถานะรอง |
| --- | ---: |
| Common | 1 |
| Rare | 2 |
| Epic | 3 |
| Legend | 4 |

แก้จำนวนใน `src/config/equipment.json` → `secondaryCounts` การสุ่มแต่ละชิ้นเลือกสถานะรองไม่ซ้ำกัน ค่าสถานะหลักยังมีเสมอ อุปกรณ์เดิมเก็บค่าสุ่มเดิมเพื่อรักษาของผู้เล่น ไม่สุ่มทับเมื่อโหลดเซฟ

## การคลิกไอเท็ม

- คลิกซ้ายเปิดรายละเอียดค้างไว้ พร้อมปุ่มไอคอนตามชนิดไอเท็ม มีชื่อสำหรับชี้เมาส์และโปรแกรมอ่านหน้าจอ
- คลิกขวาใช้งานหรือสวมใส่ทันที
- ยาฟื้นฟูมีใช้และขาย อุปกรณ์มีขาย สวมใส่ ตีบวก และย่อย
- Legend ย่อยไม่ได้ ต้องถอดอุปกรณ์ที่สวมอยู่ก่อนขายหรือย่อย
- มือถือแตะไอเท็มแล้วแตะปุ่มในหน้าต่างรายละเอียดเพื่อใช้งาน

## วัตถุดิบที่ได้จากการย่อย

อาวุธและเครื่องประดับคืน **Shade essence + Rune stone** หมวก เสื้อ กางเกง และรองเท้าคืน **Shade essence + Sky feather** วัตถุดิบมี rarity เดียวกับอุปกรณ์ จำนวนในตารางเป็น **อย่างละ** ไม่ใช่จำนวนรวม

| Lv อุปกรณ์ | Common | Rare | Epic |
| --- | ---: | ---: | ---: |
| 10 | 2 | 1 | 1 |
| 30 | 2 | 2 | 1 |
| 50 | 3 | 2 | 1 |
| 70 | 3 | 3 | 1 |
| 90 | 4 | 3 | 1 |

ตัวอย่าง: อาวุธ Common Lv10 คืน Shade essence Common 2 และ Rune stone Common 2; เสื้อ Rare Lv70 คืน Shade essence Rare 3 และ Sky feather Rare 3

การย่อยใช้ค่าเลเวลและ rarity ของอุปกรณ์ ไม่มีการคืนเงิน ค่าตีบวก หรือหินตีบวก ถ้าพื้นที่กระเป๋าไม่พอเก็บผลลัพธ์ครบทั้งสองชนิด การย่อยจะไม่เกิดขึ้นและอุปกรณ์ยังอยู่ เซิร์ฟเวอร์ตรวจคำสั่งและบันทึกผลร่วมกันเพื่อป้องกันการส่งคำสั่งซ้ำแล้วรับของซ้ำ

## ตั้งค่าและขายไอเท็ม

ค่าแยกอยู่ใน `src/config/salvage.json`: `levels` จำนวนคืนอย่างละ, `materials` วัตถุดิบตามประเภท, `sale` ราคาขาย เมื่อแก้ JSON ต้อง rebuild/deploy client และ server พร้อมกัน อุปกรณ์เลเวลอื่นที่มีอยู่เดิมใช้แถวเลเวลใกล้ที่สุดที่ไม่เกินเลเวลอุปกรณ์; ต่ำกว่า Lv10 ใช้แถว Lv10

ปุ่มขายขายครั้งละ 1 ชิ้น ยาขายคืน 50% ของราคาซื้อปัดลง อุปกรณ์ขาย 50% ของราคาอุปกรณ์/ราคาคราฟต์ คูณ rarity Common 1, Rare 1.25, Epic 1.5, Legend 2; วัตถุดิบชิ้นละ 6 z ตามระบบเดิม EXP Charm และ EXP Tome สำหรับทดสอบไม่ขาย การขายไม่เพิ่มราคาตามการตีบวก

## หลักฐานตรวจรับ

- Production build ผ่าน; TypeScript ผ่าน (มีคำเตือนขนาด bundle เดิม)
- ระบบเกม/เซิร์ฟเวอร์ 65 tests ผ่าน รวมการสุ่มสถานะรอง วัตถุดิบแต่ละช่องและทุกระดับ กระเป๋าเต็ม การแยก rarity คำสั่งซ้ำ เซฟ บัญชี และระบบตีบวก
- Browser 3 tests ผ่าน: คลิกซ้ายค้างรายละเอียด คลิกขวาสวมใส่/ใช้ ขายยาทีละหนึ่ง ย่อยอาวุธ/เสื้อพร้อมตรวจจำนวนวัตถุดิบจริง ตีบวกเลือกชิ้นถูก และหน้าต่างพอดี 1200×800/390×844
- รอโมเดลครบและตรวจไม่มี page/model error ภาพ: `artifacts/inventory-actions-desktop.png`, `artifacts/inventory-actions-mobile.png`
- Browser ใช้ Chromium/SwiftShader ตรวจพฤติกรรมและ layout ไม่ใช่ผล FPS เครื่องผู้เล่น
