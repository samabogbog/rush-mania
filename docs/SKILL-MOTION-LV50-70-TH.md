# การเคลื่อนไหวสกิล Lv50–70

ผู้เล่นพอใจ VFX แล้ว งานนี้แก้เฉพาะ choreography และการขับ animation ของตัวละคร ครบ 18 สกิลจากสามอาชีพสองสาย ไม่เปลี่ยนไฟล์ skill-vfx.ts เวลาร่าย/recovery สามเท่า MP cooldown ดาเมจ เซฟ และ authoritative simulation

ปัญหาเดิม: การกระโดดและตีลังกายาว 78% ของ recovery ทำให้ตัวละครลอยเกินหนึ่งวินาทีเมื่อเวลาสกิลเพิ่มสามเท่า ส่วน animation live เดินเองตาม speed แต่ preview ใช้ seek จึงมีจังหวะต่างกัน

แนวทาง: ใช้เวลาจริงเป็นวินาที แยกเตรียมย่อเข่า .075 วินาที วิถีพาราโบลาที่ g=9.8 หน่วย/วินาที² ช่วงลอย .42/.44/.46 วินาทีสำหรับ Lv50/60/70 ลงพื้นภายใน .54 วินาทีและรับน้ำหนัก .16 วินาที จากนั้นใช้ท่าโจมตี/เล็ง/ร่ายต่อเนื่องจนจบ recovery เดิม สายป้องกัน Lv50/70 ยืนรับน้ำหนักกับพื้น ท่าหมุน Lv70 จบก่อนลงพื้น ท่าร่ายยาวมีจังหวะมือ/เล็งโดยไม่ยืดเวลาลอย

ใช้ clip ข้อต่อเดิมของโมเดล ผูก live และ preview กับนาฬิกาเดียวกัน นักธนูแยกชั้นมือเล็งออกจากขากระโดดเพื่อรักษาอาวุธอยู่ในมือและไม่ต่ำกว่าเท้า HP ลดระหว่างท่าไม่ทำให้ตัวละครกระตุกลงพื้น; การตาย/ยกเลิก/ซ่อนตัวละครยังคืนท่าตามปกติ การเปลี่ยนตำแหน่งเป็น offset ภายในโมเดล ไม่ย้ายตำแหน่ง simulation หรือ collision

หลักฐานแยกสองชุด: render-only กล้องใกล้โดยไม่แสดง VFX เพื่อดูสรีรวิทยาและเท้าสัมผัสพื้น กับการเรียนและร่ายผ่าน UI ในฉากจริงครบ 18 สกิล รายงานเครื่อง Chromium ANGLE SwiftShader; ผลนี้ไม่รับรอง FPS บนอุปกรณ์ผู้เล่น

การเคลื่อนไหวต่อหลังปล่อยสกิลเป็นงานแสดงผล ไม่เพิ่มจำนวน hit ของ Simulation ไม่แก้ VFX ที่ผู้เล่นอนุมัติ ตัวละครยังเป็นโมเดลชิบิและใช้ข้อต่อ/คลิปเดิม; วิถีแรงโน้มถ่วงและการเปลี่ยนท่าช่วยให้ดูมีน้ำหนัก ไม่ใช่ full-body rigidbody simulation

ตรวจรับ runtime รอบสุดท้าย: build และ 65 checks ผ่าน (43 code +1 ตรวจท่าจาก capture +21 browser) ภาพกล้องใกล้ 168 เฟรม การเล่นท่าต่อเนื่องครบ18 และการเรียน/ร่ายผ่าน UI ครบ18 ยืนยันตำแหน่งและมุมท่าในเกมตรงกับ deterministic choreography, MP/cooldown/kill/release cue, disposal, model/page error0 วิถีอากาศและการลงพื้นต่อเนื่อง อนุมัติขอบเขตการเคลื่อนไหวเพื่อเผยแพร่ ผู้เล่นตรวจต่อได้
