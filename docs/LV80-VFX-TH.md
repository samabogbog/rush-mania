# VFX Lv80 และแรงสั่นสกิลระดับสูง

ตรวจไอคอนจริงและ description ครบหกตาม artifacts/lv80-vfx/ICON-AUDIT-TH.md ใช้ Lv70 เป็นฐาน (รูปทรงหลัก .96 วินาที คลื่นตกแต่งรัศมี12.6 จบ1.54 วินาที) เพิ่มความยิ่งใหญ่ด้วยรูปทรงเฉพาะและคลื่นหลายจังหวะ รัศมีภาพไม่เพิ่มรัศมีดาเมจ

งานนี้แก้ VFX Lv80 ทั้งหกและเพิ่มกล้องสั่นตอน release Lv80/90/100 เท่านั้น แรงสั่น Lv80 เบาและไล่เพิ่มตามระดับ ระยะสั้นและคืนศูนย์ ไม่สะสม drift ไม่สั่น HUD ไม่เปลี่ยน zoom หรือตำแหน่ง simulation ไม่แก้ MP cooldown damage DOT slow เซฟ/server authority และเวลาร่าย/recovery สามเท่า รักษาการเคลื่อนไหว Lv50–70 ที่ตรวจรับแล้ว

เปรียบเทียบ Lv70/Lv80 Low/High ด้วยกล้องเดียวกัน แยก preview ออกจากการเรียนและร่าย rank1 ผ่าน UI จริงครบหก ตรวจแรงสั่นจาก release จริงและการคืนศูนย์ พร้อม pool/material/disposal และ server-authoritative/timing regression หลักฐานภาพ คลิป และ performance อยู่ใน artifacts/lv80-vfx ค่าจาก Chromium ANGLE SwiftShader ไม่ใช่ FPS เครื่องผู้เล่น


| ระดับ | แรงสั่นสูงสุด (หน่วยโลก) | ระยะเวลา |
| --- | ---: | ---: |
| 80 | 0.045 | 0.24 วินาที |
| 90 | 0.075 | 0.30 วินาที |
| 100 | 0.110 | 0.36 วินาที |

แรงลดด้วย envelope กำลังสอง ใช้ offset เดียวกับตำแหน่งกล้องและจุดเล็ง เริ่มแสดงในเฟรม release ก่อนนับเวลาของเฟรมถัดไป จึงไม่หายก่อนวาดเมื่อเครื่องแสดงผลช้า แรงซ้อนเลือกค่าที่แรงกว่าแทนการบวก และปิดเมื่อระบบตั้ง prefers-reduced-motion: reduce

Lv80 เพิ่มรูปทรงหลักเป็น 1.16 วินาที คลื่นตกแต่งสามจังหวะถึงรัศมี 14.4 และจบที่ 1.86 วินาที Low จำกัด 40 ชิ้น High 96 ชิ้น และ pool 160 ชิ้น รูปทรงกวาง ธง และเมฆสร้างจาก geometry ร่วมและ material ถาวร ไม่มี sprite หรือ texture ใหม่


ตรวจรับ build สุดท้าย: build ผ่าน, code/regression 55 รายการ และ browser 12 รายการ รวม 67 รายการ โดย 9 รายการเป็น preview/การร่าย Lv80 และ 3 รายการตรวจแรงสั่น Lv90/Lv100/Reduce Motion ภาพเปรียบเทียบ 96 เฟรมใช้กล้องเดียวกัน ไม่มี page/model error และทุกสกิลกลับสู่สถานะไม่มี motion/VFX ค้างหลังจบ

ผู้ควบคุมเปิดตรวจภาพ High/Low ทั้งหก ภาพเทียบ Lv70 และภาพเรียงตามเวลาจากคลิป preview ทั้งสามกับคลิปร่ายจริงทั้งหกแล้ว อนุมัติขอบเขต Lv80: Hamstring คมตัดต่ำ, Standard ธงแดง/ดาบทอง, Venom กลุ่มเมฆพิษ, Spirit กวางวิญญาณ, Poison ลูกศร/หางพิษ, Entangling ลูกศร/เถาวัลย์ อ่านความแตกต่างและจังหวะปิดท้ายได้ทั้ง Low/High ดาบทองในกล้องเล่นจริงอยู่ในสนาม แรงสั่นจริงที่บันทึกมี amplitude 0.045/0.075/0.110 ตามระดับ กลับ inactive/offset ศูนย์ และ Reduce Motion ไม่มี shake สรุปนี้ไม่ใช่คะแนนงานภาพทั้งเกมหรือการรับรอง FPS เครื่องผู้เล่น

ผลทดสอบ Lv100 ครั้งแรกติดเงื่อนไข fixture ที่สมมุติว่า VFX ทุกระดับมีมากกว่า 5 ชิ้น โหมด Low ของ Meteor Blade เดิมมีน้อยกว่านั้น แก้เฉพาะชุดทดสอบแรงสั่นให้ตรวจว่า VFX ออกจริงและ motion/camera ตรงสกิล พร้อมหลักฐาน MP/cooldown/kill โดยไม่แก้ VFX Lv90/100
