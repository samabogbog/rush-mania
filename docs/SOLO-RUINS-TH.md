# เข้า Rootheart Ruins คนเดียว

Rootheart Ruins เปิดให้ผู้เล่นเลเวล 70 ขึ้นไปเข้าเดี่ยวโดยไม่ต้องสร้างปาร์ตี้ ห้องเดี่ยวแยกตามตัวละคร ส่วนปาร์ตี้ใช้ห้องร่วมเดิมและรองรับ 1–4 คน ผู้เล่นที่เหลือคนเดียวในปาร์ตี้ยังอยู่ในดันเจียนได้เมื่อเพื่อนออกจากปาร์ตี้

ยังต้องเดินถึงประตูเหนือและออกจากการต่อสู้ก่อนย้ายแมพ ค่ามอนสเตอร์ รางวัล อัตราดรอป และความก้าวหน้าของตัวละครไม่เปลี่ยน ห้องเดี่ยวเก็บสถานะระหว่างหลุดการเชื่อมต่อ และเก็บกวาดหลังเจ้าของออกจากห้อง

การตรวจ: build และชุดทดสอบ authoritative `solo-ruins.spec.ts` กับ `community-economy.spec.ts` ครอบคลุมห้องเดี่ยวแยกกัน การเชื่อมต่อกลับ เงื่อนไขเลเวล/ประตู/การต่อสู้ ห้องปาร์ตี้ และระบบชุมชนเดิม

ผลตรวจสุดท้าย: build ผ่าน, authoritative checks 17 รายการและ browser menu 1 รายการผ่าน ภาพหน้ารายละเอียดแมพอยู่ใน `artifacts/solo-ruins/map-entry.png` การทดสอบเก่าอีก 2 รายการ (`party combat`, `server owns movement`) ไม่ผ่านเหมือนกันทั้ง HEAD ก่อนแก้และรอบนี้: fixture รอร่ายเพียง 400ms แม้สกิลร่าย 1.05s และ fixture ต่อสู้เดิมไม่ฆ่ามอนสเตอร์ภายในเวลาที่กำหนด จึงไม่รวมสองรายการนี้เป็นผลผ่านและไม่เปลี่ยนระบบต่อสู้ในงานนี้
