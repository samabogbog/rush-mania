# ปุ่มมือถือและ Auto

บนหน้าจอกว้างไม่เกิน 900px ใช้จอยวงกลมด้านซ้ายลากเพื่อเดิน: ระยะลากกำหนดความเร็ว มี deadzone 16% และจำกัดความเร็วสูงสุดเท่า WASD จอยจับ pointer จนปล่อย; เมื่อปล่อย ยกเลิก touch เสีย pointer capture สลับหน้าต่าง ซ่อนหน้า เปิดเมนู หรือเปลี่ยนขนาดหน้าจอ จะคืนศูนย์ทันที ปุ่ม AUTO ใหญ่ด้านขวาใช้สถานะเดียวกับปุ่ม Auto ใน hotbar (`aria-pressed`) แนวตั้งวางเหนือ hotbar; แนวนอนเตี้ยวางสองข้าง hotbar

Auto ใช้เฉพาะสกิลที่เรียนและใส่ในช่อง 1–6 เท่านั้น ตรวจ MP, cooldown, ระยะ, สิ่งกีดขวาง และสถานะร่าย/ตาย ใช้ช่องวนต่อจากสกิลล่าสุดเพื่อให้ทุกช่องมีโอกาส ร่ายครั้งละหนึ่งสกิล; หากไม่มีสกิลพร้อมใช้จะโจมตีธรรมดาเมื่อเป้าหมายอยู่ในระยะ ไม่ใช้ potion หรือช่อง auxiliary อัตโนมัติ เมื่ออยู่ในวงกลุ่มจะยืนให้มอนสเตอร์เข้าหา และไม่เดินระหว่างร่าย; นอกวงยังเดินเข้าโจมตีตามพฤติกรรมเดิม กติกาอยู่ใน simulation ร่วม โดยออนไลน์ตัดสินบน server และ client ส่งเฉพาะคำสั่งเปิด/ปิด Auto

วง cooldown บนสกิลเริ่มเทาเต็มปุ่มและเปิดภาพตามเข็มนาฬิกาจาก 12 นาฬิกา จนใสหมด บันทึกเวลารวมหลังลด cooldown ตอนร่าย จึงไม่เปลี่ยนสัดส่วนกลางคันเมื่อเปลี่ยน gear ออนไลน์ใช้เวลาที่เหลือจาก snapshot และประมาณเวลาระหว่าง snapshot เพื่อแสดงผลลื่น; จำนวน MP/damage/cooldown จริงยังเป็นของ server สำหรับ actor เก่าที่ไม่มีเวลารวม ใช้เวลาคงเหลือครั้งแรกเป็นจุดเริ่มโดยไม่ล้าง cooldown

QA selectors: `#mobile-joystick`, `.stick-knob`, `#mobile-auto`, `.skill-slot[data-skill]` สัดส่วนคงเหลือ `data-cooldown-ratio` เป็น 1→0 และ CSS `--cooldown-progress` เป็น 0%→100% snapshot อ่านอย่างเดียวมี `joystickInput`, `joystickActive`, `auto`, `cooldownRatios`, `skillCooldownTotals`.
