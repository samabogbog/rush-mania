# รูปแบบฉากตามภาพอ้างอิง

เป้าหมายจากภาพที่ผู้ใช้แนบ: ฉากไดโอรามาชนบท แสงแดดอุ่น เงานุ่มและมีน้ำหนัก หญ้าเขียวมะกอก/เสจ ทางเดินสีดิน บ้านผนังสีครีม หลังคาดินเผา ต้นไม้หลายเฉด ดอกเดซี่สีงาช้าง กอหญ้าปลายเรียว และรายละเอียดริมทาง

งานนี้ใช้ภาพเป็นทิศทางการออกแบบ ไม่คัดลอกข้อความ โลโก้ ตัวละคร หรือฉากทั้งภาพ องค์ประกอบฉากและวัสดุที่เพิ่มสร้างด้วย geometry/texture procedural ของโปรเจกต์ ไม่มีการเพิ่ม asset ภายนอกที่ต้องขอสิทธิ์

เก็บภาพก่อนแก้จาก source `0ad318bb7cbf73c19e728fe51302449d59389b81` ที่ town/glade high 1200×800 และ glade low 390×844 รอ GLB ครบทุกภาพ ตรวจ modelErrors และ pageErrors เป็นศูนย์ ใช้ fixture ตัวละครเลเวล 100 ในโหมด practice เคลื่อนผ่าน input จริงและเปิด/ปิด Auto ผ่านปุ่มเดสก์ท็อป/มือถือ เก็บสถิติ draw calls/mesh/material/texture/frame ใน `artifacts/reference-environment/before` รอบแรกแก้ fixture ปุ่ม Auto มือถือให้ใช้ `#mobile-auto` แล้วตรวจใหม่

กรอบการเปลี่ยนแปลง: ปรับ renderer เท่านั้น คงสูตรตัวละคร สมดุลมอนสเตอร์ อัตราดรอป สกิล VFX collision และ save schema เดิม ทุกพื้นที่มีอัตลักษณ์เดิม รวมถึง frost/marsh/ruins รายละเอียดใหม่เป็นของตกแต่ง จัดนอกแนวเดิน จุดเกิด NPC/portal และบริเวณกลางกลุ่มมอนสเตอร์ แยกชุดรายละเอียดเพิ่มเติมที่แสดงเฉพาะ high/auto ใช้ geometry ที่รวมเป็นชุด และวัสดุ/texture ร่วมเพื่อจำกัดทรัพยากร

หลักฐานหลังแก้และผลตรวจรับจะบันทึกหลังเจ้าของ runtime ประกาศ READY/FROZEN เท่านั้น ก่อนเผยแพร่ผู้ควบคุมต้องเปิดดูภาพจริง ตรวจ gameplay และ low/high quality รวมถึงการสลับพื้นที่/คุณภาพไม่สะสมทรัพยากร Performance จาก Chromium SwiftShader ใช้เปรียบเทียบสภาพแวดล้อมเดียวกัน ไม่ใช่การรับรอง FPS เครื่องผู้เล่น

## การปรับที่ส่งมอบ

แสงแดดสีครีมอุ่นเข้มขึ้น ลดแสงเติมฟ้า/พื้น และเพิ่มน้ำหนักเงาแบบ blur-close-exponential โหมด high ยังใช้ shadow map 2048 และ low ใช้ contact shade แบบ gradient มุมกล้องเปลี่ยนจาก 29/24 เป็น 26/28 เพื่อเห็นด้านหน้าบ้านและรูปทรงฉากมากขึ้น

renderer ใช้ palette แยกจากข้อมูลเกม: town/glade/orchard เขียวอมเหลือง, marsh เขียวเสจ, frost ฟ้าอมเทา, ruins เขียวหม่น ทางเดินใช้สีทราย/ดิน วัสดุหญ้ามี grain ละเอียดและ broad variation น้อยลงหลังเปิดดูชุดแรกแล้วพบลายด่างมากเกิน บ้านหลังคาลาดดินเผามีแนวกระเบื้องและหน้าจั่วครีม กระจกสีอำพัน

เพิ่มกอหญ้าใบกว้างเดซี่และผลเบอร์รีรวม 990 กลุ่มต่อพื้นที่ แบ่ง sector ละ 80 base + 30 high; low ยังแสดง base ครบ เพิ่ม contact shade ตาม obstacle เดิม ต้นไม้เล็ก 5 ต้นใน glade ยึดตำแหน่งก้อนหินที่มี collision เดิม และใบบัว/ดอกบัว/หินริมบึงใน marsh

## ผลตรวจรับ

`npm run build` ผ่าน; 15 code checks และ 10 browser checks ที่ไม่ซ้ำ รวม 25 ผ่านบน source สุดท้าย เปิดดูภาพทั้ง 6 พื้นที่ มือถือ และมุมใกล้บ้านจริง ตรวจ GLB ครบและ modelErrors/pageErrors = 0 เดินและเลือกเป้าหมายผ่าน input จริง ร่ายสกิลที่เรียนตามกติกาเกมแล้ว MP 852→827, kills 0→1 บันทึกใน `artifacts/reference-environment/gameplay.json` และวิดีโอ `gameplay.webm`

ตรวจย้ายพื้นที่ 18 ครั้ง: อุ่น cache ครบ 6 พื้นที่หนึ่งรอบ แล้วเทียบสองรอบถัดไปในพื้นที่เดียวกัน mesh/material/texture เท่ากันทุกพื้นที่ ต้องรอ palette ของ renderer ตรงกับพื้นที่ก่อนเก็บ snapshot เพราะ save.zone เปลี่ยนก่อน render rebuild หนึ่งเฟรม การทดสอบรอบต้นที่เก็บก่อนเฟรมใหม่และเทียบข้ามพื้นที่ถูกทิ้งแล้วแก้ fixture ตรวจใหม่

static vertices สูงสุด 217708 จากงบเดิม 220000; surface textures สูงสุด 12 และภาพเทียบ matched view ไม่มีจำนวน texture เพิ่ม high draw calls ของ town 71→93 และ glade 121→151; low glade 24→38 การเพิ่มเป็น geometry รายละเอียดและ contact shade ที่รวมเป็น batch โหมด low ปิด live shadows/normal maps และ high-only grass โดยคงพืช base กับสีหลัก

ข้อมูล sampled frame p50/p95 และ resource counts อยู่ใน `performance.json` จำนวน frame สำหรับ high ในช่วงวัดสั้นมีเพียง 2–3 frame จึงเป็นการวินิจฉัย มิใช่ benchmark ทางสถิติ baseline ไม่ได้เก็บ p50 ไม่อ้างผล 60/30 FPS ของเครื่องผู้เล่น

ผู้ควบคุมเปิดภาพแล้วอนุมัติรูปแบบฉากรอบที่สอง: แสง/เงามีมิติ สี olive/cream/terracotta สอดคล้องภาพอ้างอิง และพืชอ่านรูปทรงได้ในระยะเล่น ประเมินส่วนฉากประมาณ 8/10 จากภาพจริง เป็นความเห็นด้านศิลป์ ไม่ใช่คะแนนทั้งเกมหรือความพร้อมเปิดบริการ รูปแบบตัวละคร อาคาร และ layout ยังคงเป็นงานของโปรเจกต์เอง มิใช่สำเนาภาพอ้างอิงทุก pixel
