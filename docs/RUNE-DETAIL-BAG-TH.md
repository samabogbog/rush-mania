# รายละเอียดรูนและกระเป๋า 5 หน้า

รายละเอียดอุปกรณ์ส่วน Rune slots แสดงชื่อค่าสถานะพร้อมค่า เช่น Damage bonus +9.1% และ Critical chance +6.5% ชื่อสถานะยังแสดงในตัวอย่างผลลัพธ์การฝัง/คราฟ/อัปเกรดด้วย

หน้า Upgrade 2 → 1 แสดงวัตถุดิบสองชิ้นเป็นไอคอน ไม่มี Copy หรือแถวชื่อวัตถุดิบซ้ำด้านล่าง การเลือกและคำสั่งยังอ้าง ID ของรูนจริง และมีชื่อสำหรับโปรแกรมอ่านหน้าจอ

กระเป๋าเพิ่มจาก 144 เป็น 240 ช่อง แบ่ง 5 หน้า หน้าละ 48 ช่อง กติกาเพิ่มไอเท็ม คราฟ ซื้อขาย คืนรูน และ Claim into bag ใช้ความจุเดียวกันทั้งเกมและเซิร์ฟเวอร์ เซฟเดิมและรายการรูนรอรับยังอยู่ครบ ไม่เปลี่ยน schema เซฟ

Build ผ่านและทดสอบ 45 รายการ: กติกา/เศรษฐกิจ/เซฟ 38, config 5, browser 2 flow บนจอ 1200×800 และ 360×740 ตรวจเปิดครบห้าหน้า ชื่อโบนัสสองชนิด และอัปเกรดสำเร็จจากไอคอนที่เลือก หลักฐานอยู่ใน artifacts/rune-detail-bag การทดสอบใช้ Chromium/SwiftShader สำหรับความถูกต้องและการจัดวาง ไม่อ้าง FPS เครื่องผู้เล่น
