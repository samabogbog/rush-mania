# หน้าตีบวกอุปกรณ์

แยกแท็บ Craft และ Refine ใน Forge เลือกอุปกรณ์จากช่องไอเท็มโดยใช้ ID ของแต่ละชิ้น แสดงระดับตีบวก ความหายาก สถานะสวมใส่ และค่าสถานะเพื่อแยกไอเท็มชื่อซ้ำ รายละเอียดแสดงโอกาสสำเร็จ ค่าใช้จ่าย และความเสี่ยงเมื่อล้มเหลวตามกติกาเดิม

ข้อความผลสำเร็จ/ล้มเหลวแสดงในหน้าตีบวก โหมดออนไลน์รอผล authoritative ก่อนเปลี่ยนข้อความ ล็อกการกดซ้ำระหว่างรอผล ทางลัด Refine จาก Bag เปิดแท็บและเลือกชิ้นเดียวกัน

ชุดตรวจ UI ครอบคลุมอุปกรณ์ชื่อซ้ำ ผลสำเร็จ/ล้มเหลว การคราฟแยกแท็บ มือถือ และทางลัดจาก Bag การตรวจ NetworkSimulation ใช้ browser จริงกับ transport จำลองที่เรียก server/realm.transact จริง พร้อมหน่วงคำตอบเพื่อทดสอบ pending และป้องกันคำสั่งซ้ำ ไม่ใช้บัญชี production ในการสร้าง fixture

ผลตรวจ: build ผ่าน และ 21 tests ผ่านบน source สุดท้าย (12 material/craft authority + 6 refinement rules/authority + 3 browser flows) เปิดดูภาพ desktop/mobile แล้ว ชุดเก่า craft-ui มี recipe ID ที่ถูกเลิกใช้ในชุดอุปกรณ์ปัจจุบัน ส่วน legacy refinement migration test คาด save version 9 แม้ปัจจุบันเป็น 10 จึงไม่รวม fixture เก่าเหล่านี้เป็นผลตรวจผ่าน
