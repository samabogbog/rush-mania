# VFX สกิล Lv10 รอบแรก

ปรับเฉพาะสกิลที่ปลดล็อก Lv10 ของทั้งสองสาย ทุกอาชีพ รวม 6 สกิล ใช้รูปทรง 3D จริง ไม่มี sprite หรือภาพแปะ

| อาชีพ / สกิล | ภาพหลัก |
| --- | --- |
| นักดาบ · Power Strike | คมฟันใหญ่ ลำแสงจากอาวุธ แกนระเบิดที่เป้าหมาย คลื่นกระแทกและสะเก็ดพุ่งรอบจุดโดน |
| นักดาบ · Bulwark Crash | เกราะพลังชั่วครู่ เสาแสงฟาดจากด้านบน คลื่นวงกลมซ้อน เศษพื้นกระเด็นจากตัวผู้ร่าย |
| นักเวท · Fire Bolt | ลำแสงไฟและลูกไฟพุ่งไปเป้าหมาย แกนร้อนสว่าง วงระเบิดเอียงและประกายไฟรอบวง |
| นักเวท · Bramble Bolt | ลำแสงสีเขียว เกลียวพลังและหนามงอก ใบไม้กระเด็นเป็นวงกว้าง |
| นักธนู · Power Shot | ลำแสงทะลวงสีทอง ลูกศรพุ่ง แกนกระแทกและสะเก็ดแสงกระจาย |
| นักธนู · Snaring Arrow | ลำแสงและลูกศร วงพลังพันเป้าหมายหลายชั้น รากและสะเก็ดพลังสีเขียว |

เตรียมร่ายมีวงพลังหุบและพลังรวมเข้าแกนกลาง กระแทกหลังออกสกิลประมาณ 0.08 วินาทีสำหรับนักดาบ / 0.14 วินาทีสำหรับระยะไกล แล้ววงคลื่นขยายและอนุภาควิ่งออกอย่างรวดเร็ว สลายภายในประมาณหนึ่งวินาที

รัศมีเอฟเฟกต์ตกแต่งประมาณ 3.4 หน่วย แยกจากระยะดาเมจจริง ไม่มีการเปลี่ยนค่าเลเวล สกิล แต้ม MP คูลดาวน์ เป้าหมาย ดาเมจ หรือข้อมูลบัญชี

## จำกัดต้นทุน

- Geometry และ material ใช้ร่วมกัน; mesh นำกลับมาใช้ใหม่
- Active mesh จำกัด 40 ใน Low / 96 ใน High; pool ไม่เกิน 160
- High กระจายหลัก 16 ชิ้น บวกประกายเล็ก 5 ชิ้นและคลื่น 3 ชั้น; Low เก็บลำแสง แกนระเบิด และรูปหลักไว้ โดยลดอนุภาคเป็น 8 ชิ้นและคลื่น 2 ชั้น
- ไม่เพิ่มแสง dynamic หรือ post-processing ทั้งจอ จึงไม่ต้องเปิด bloom เพื่อเห็นลำแสง
- Clear/dispose ปิดและคืน mesh/material ของระบบ VFX

## ตรวจรับ

Production build และการทดสอบระบบ 25 ข้อผ่านหลังแก้สีรอบสุดท้าย รวมทุก60สกิล การ reuse/dispose การมีปริมาตรจริงทั้ง Low/High และกติกาสกิลเดิม

Browser ตรวจ 9 กรณี: preview แยก3อาชีพ × สองสาย × Low/High ที่0.08/0.24/0.52วินาที พร้อมวิดีโอ release ที่อนุภาคสลายเอง; และร่ายสกิลที่เรียนจริง6สกิลในเกม โดยตรวจ MP คูลดาวน์ ศัตรูตาย metadataของเอฟเฟกต์และ active=0 เมื่อจบ ไม่มี page/model error โมเดลโหลดครบก่อนบันทึก

ตัวละครทดสอบเป็น Lv100 แต่เรียนสกิล Lv10 ขั้น1 เพื่อไม่ตายระหว่างบันทึก ไม่ได้ปรับเซฟหรือค่าเกมของผู้เล่น production ดูผลจริงแยกจาก render-only ใน `artifacts/lv10-vfx/gameplay-summary.json`; ภาพรวม `six-skills-contact.png` และภาพการเคลื่อนไหวที่สกัดจากวิดีโอ

งบที่เห็นในภาพ impact0.24s: High26–32 / Low12–18 active meshes ส่วนการร่ายจริง poolที่อุ่นแล้ว37–41และกลับactive0 ค่า poolเป็นทรัพยากรที่รอ reuse ไม่ใช่การรั่ว โปรแกรมทดสอบร่ายทุก60สกิลซ้ำหลายรอบตรวจว่า pool ไม่เกิน160และ dispose คืน scene meshes/materials

ผู้ควบคุมตรวจ PNG และภาพจากวิดีโอจริง: VFXเฉพาะชุดLv10ประเมิน8/10 จาก silhouette ลำแสง สีแยกธีม ระยะกระจายและจังหวะกระแทก เป็นการประเมินภาพของหกสกิลรอบนี้ ไม่ใช่คะแนนทั้งเกม

สภาพแวดล้อม: Chromium/ANGLE/SwiftShader เป็น software renderer ค่า FPS/frameP95/drawCalls ของฉากเต็มที่บันทึกในไฟล์ gameplay เป็นข้อมูลสภาพแวดล้อมทดสอบ ไม่รับรอง FPS เครื่องผู้เล่น

แก้ fixtureก่อนตรวจสุดท้ายให้ใช้ปุ่มเดินหยุดเมื่อถึงเขตแล้วรออย่างน้อย4ศัตรูในระยะที่สกิลขั้น1โจมตีได้ แทนการรอทุก6ตัวอยู่ใกล้กว่า1.6หน่วยและการถึงพิกัดเป๊ะ จึงตรวจการร่ายจริงตามจำนวนเป้าหมายที่ต้องการได้ นอกจากนี้แยก fixture ใหม่ให้ VFXอัปเดตต่อจนสลายหลังท่าตัวละครจบ ไม่หยุดอนุภาคค้างเพื่อถ่ายวิดีโอ
