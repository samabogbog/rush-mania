# หน้าตีบวกแบบกะทัดรัด

ใช้ช่องไอเท็มแบบเดียวกับ Bag มีรูป ระดับตีบวก และเครื่องหมาย E ของชิ้นที่สวมใส่ แสดงข้อมูลชื่อ/ความหายาก/ค่าสถานะเฉพาะชิ้นที่เลือก ตัดรหัสไอเท็มยาว ข้อความแนะนำซ้ำ และตารางอัตราสำเร็จออกจากหน้าหลัก

ยังแสดงหินที่เลือก โอกาสสำเร็จ ค่าใช้จ่าย ความเสี่ยงเมื่อล้มเหลว และข้อความผลตีบวก ไอเท็มจำนวนมากใช้ปุ่มเปลี่ยนหน้าแทนการเลื่อนแนวตั้ง แต่ละช่องยังอ้างอิง ID ของอุปกรณ์ชิ้นเดิมและผลออนไลน์รอเซิร์ฟเวอร์เช่นเดิม

QA วัดขนาดจริงบน 1200×800, 390×844 และ 360×740 พร้อมอุปกรณ์ 60 ชิ้นที่มี secondary stats 5 ค่า ตรวจว่า panel ไม่ล้น ไม่มีการเลื่อนแนวตั้ง/แนวนอน ปุ่มยืนยันอยู่ในจอ เปลี่ยนหน้า เลือกชิ้นที่ชื่อซ้ำ และตีบวกแล้วเปลี่ยนเฉพาะชิ้นที่เลือก

ผลตรวจ source สุดท้าย: build ผ่าน และ browser flows 6 รายการผ่าน (3 ขนาดจอพร้อม pagination/ผลตีบวก, duplicate item/craft tab, mobile Bag shortcut, NetworkSimulation pending/authoritative success/failure) เปิดดูภาพเดสก์ท็อปและมือถือจริงแล้ว ไม่มีการซ่อนส่วนล้นเพื่อให้ผ่านการวัด
