# ค่าสถานะรองฟื้น HP/MP ตามเลเวลอุปกรณ์

เพดานสุ่มเพิ่มเป็นเส้นตรงจากอุปกรณ์ Lv10 ถึง Lv90 โดยยังสุ่มค่าต่ำสุด 0.1%/วินาที และปัดค่าเป็นทศนิยม 2 ตำแหน่งเช่นเดิม ต่ำกว่า Lv10 ใช้เพดาน Lv10; สูงกว่า Lv90 ใช้เพดาน Lv90

| เลเวลอุปกรณ์ | ฟื้น HP สูงสุด (%/s) | ฟื้น MP สูงสุด (%/s) |
| --- | ---: | ---: |
| 10 | 0.20 | 0.30 |
| 30 | 0.23 | 0.35 |
| 50 | 0.25 | 0.40 |
| 70 | 0.28 | 0.45 |
| 90 | 0.30 | 0.50 |

ใช้สูตรเดียวกันในการสุ่มอุปกรณ์ ดรอป คราฟ สร้างไอเท็มแบบ max roll และประเมินสีคุณภาพ roll ใน UI ไม่สุ่มใหม่หรือลดค่าไอเท็มที่มีอยู่ก่อนปรับ และไม่เปลี่ยน set bonus, การฟื้นพื้นฐาน, ค่าสถานะรองอื่น หรือกติกาตีบวก

ผลตรวจ: build ผ่าน และ 28 unique tests ผ่าน ครอบคลุมการสุ่มจริงทุก tier, max roll/quality UI, ค่าฟื้นใน simulation, การรักษาของเดิม, authoritative grants/craft และ validation ปฏิเสธช่วงระดับกลับด้าน/เพดานผิดกติกา
