# แก้หลอด HP/MP มุมซ้ายบน

ส่วน identity-info ย่อได้จริงและชื่อไม่เพิ่ม intrinsic width ของหลอด แยกชื่อกับอาชีพเป็นสองแถว หลอด HP/MP/EXP อยู่ในกรอบ และปุ่มลูกศรมีพื้นที่ของตัวเอง ปัดค่าปัจจุบันกับค่าสูงสุดด้วย Math.round โดยไม่เปลี่ยนค่าจริงหรืออัตราส่วนหลอด

Build ผ่าน Browser ตรวจขนาด 1200×800, 800×600, 390×844, 320×568, 844×390 ยืนยันขอบหลอดและปุ่มอยู่ในกรอบ ตัวเลขไม่มีทศนิยมและ max ตรงกับค่า rounded ไม่มี page error ใช้ fixture ฝึกเล่นเลเวล100พร้อมหมวกที่เพิ่มค่าสถานะและชื่อยาว ภาพและผลตรวจ artifacts/hud-resources ใช้ Chromium SwiftShader ไม่ใช่ผล FPS เครื่องผู้เล่น
