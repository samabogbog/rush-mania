# Monster farm territories

Each map has six normal packs with 6, 7, 8, 6, 7, 8 members; existing boss and mini-boss stay separate. Town packs use beginner glade species outside the radius-16 safe hub. All other packs cycle that map's normal species, preserving existing species stats, drops, EXP and progression.

Edit `src/config/monster-groups.json`: global `radius` (2.8), `spawnRadius` (4.8), `runSpeed` (4.6 units/sec), and each map's group `id`, `x`, `z`, `count`. Use 6–8 members. Centers and spawn rings must clear collision and protected areas; focused tests cover those constraints. First pack is (0,18), except town (0,24). Town replaces its final (0,32) center with (0,-32) to separate spawn rings. Other centers are (-32,-32), (32,-32), (-32,0), (32,0), (0,32). Boss centers remain (32,32) and (-32,32).

Entering the visible circle pulls the entire living pack. Respawned members immediately reacquire a living player still in that same circle. Leaving releases territory-driven aggro; the pack returns without restoring HP. A manual hit outside the circle still triggers ordinary retaliation, chase and leash rules. `territoryAggro` distinguishes those two acquisition paths. Auto chooses only your current pack and waits for monsters to run within attack range, keeping the character stationary. Explicit movement and ground destinations still move normally. Loot collection remains manual.

Server ownership is recomputed every simulation substep. The nearest living, connected, unprotected player to the pack center in the same room owns its monsters; equal distances use player ID. Dead or disconnected owners hand off to another eligible occupant. A different actor may tick respawn without preventing reacquisition. Outside circles, normal scheduling retains a valid manual attacker owner, then a living selected attacker or nearest eligible player. Each monster is ticked once per substep.

Room layout revision 2 migrates once, matching existing monsters by species and preserving HP fraction, death/respawn timers and status where a match exists. Newly added members start healthy. Player save, inventory, accounts, balance overrides and loose loot are retained; stale target/path/cast/session references are retired.
