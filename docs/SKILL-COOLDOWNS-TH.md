# คูลดาวน์สกิลตามเลเวล

คูลดาวน์พื้นฐานของสกิลทั้ง 60 สกิล ใช้เกณฑ์เดียวกันทุกอาชีพและทั้งสองสาย: `6 + (เลเวลปลดล็อกสกิล − 10) × 6 / 90` วินาที ปัดสองตำแหน่ง

| เลเวลสกิล | วินาที |
|---|---:|
| 10 | 6 |
| 20 | 6.67 |
| 30 | 7.33 |
| 40 | 8 |
| 50 | 8.67 |
| 60 | 9.33 |
| 70 | 10 |
| 80 | 10.67 |
| 90 | 11.33 |
| 100 | 12 |

ค่านี้เป็นคูลดาวน์ก่อนโบนัสลดคูลดาวน์จากอุปกรณ์/รูน เลเวลหมายถึงเลเวลปลดล็อกสกิล ไม่ใช่ rank1–5 สูตรลดคูลดาวน์เดิมยังทำงาน และเซิร์ฟเวอร์/ไคลเอนต์ใช้ config กลางเดียวกัน

ตรวจทั้ง 60 ค่าและทดสอบ 18 รายการผ่าน ครอบคลุม rank, ลำดับสกิล, recovery, การตอบสนอง Lv90/100, server authority และ realtime prediction ไม่แก้ระยะร่าย ท่าทาง หรือ VFX
