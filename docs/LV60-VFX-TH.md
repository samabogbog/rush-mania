# VFX สกิล Lv60

ใช้ Lv50 เป็นฐานสำหรับความใหญ่ ความซับซ้อนของรูปทรง และคลื่นตามหลัง โดยตรวจไฟล์ไอคอน v4 จริงครบหกภาพกับ description ใน src/config/classes.json ก่อนออกแบบ

| สกิล | สิ่งที่เห็นในไอคอน | ความหมายจาก description / แนวทางภาพ |
| --- | --- | --- |
| War Cry Strike | นักดาบตะโกนท่ามกลางเส้นพลังแดงส้ม | โจมตีพื้นที่รอบตัว; คลื่นคำรามและคมดาบแดงขยายจากผู้ร่าย |
| Crushing Advance | นักดาบพุ่งดาบไปข้างหน้า เส้นแดงส้ม เสื้อคลุมน้ำเงิน | โจมตีและ slow; ดาบพลังพุ่งเป็นแนวและคลื่นกระแทกที่เป้าหมาย |
| Arcane Focus Strike | ลูกแก้วม่วงปล่อยลำแสงแนวนอน | โจมตีพื้นที่; แกนอาร์เคนและวงโฟกัสสีม่วงกับลำแสงเข้าสู่จุดกระแทก |
| Moonbeam | จันทร์เสี้ยวทองบนท้องฟ้า ลำแสงเหลืองขาวลงสู่ศัตรู | โจมตีและ stun; จันทร์เสี้ยวยกสูงกับลำแสงลงพื้นและวงกระแทกทอง |
| Hunter Focus Strike | ดวงตาเล็งผ่านลูกศรทอง สีมะกอก | โจมตีพื้นที่; วงเล็งรูปลักษณ์ดวงตาและแนวลูกศรทองเน้นจุดโฟกัส |
| Shock Arrow | ลูกศรฟ้าสดท่ามกลางสายฟ้าทอง | โจมตีและ stun; ลูกศรฟ้ากับสายฟ้าหักมุมทองแผ่ออกจากจุดกระแทก |

ทำเฉพาะงานแสดงผล ไม่เปลี่ยนดาเมจ ranked, MP, cooldown, ระยะโจมตี, สถานะ slow/stun, เซฟ หรือ authoritative server รักษาเวลาร่ายและคืนท่าสามเท่าที่ผู้เล่นขอไว้ ขนาดภาพตกแต่งไม่ได้เพิ่มรัศมีดาเมจจริง

การตรวจรับใช้รูปเทียบ Lv50/Lv60 ในมุมเดียวกัน Low/High, วิดีโอปล่อยเอฟเฟกต์, การเรียนและร่ายจริงผ่าน UI ทั้งหกสกิล และการตรวจ mesh pool/material/disposal พร้อมข้อมูล render frame/draw calls แยกจากผล FPS เครื่องผู้เล่น หลักฐานอยู่ใน artifacts/lv60-vfx

Lv60 เพิ่มช่วงรูปทรงหลักจาก 0.6 เป็น 0.78 วินาที และคลื่นตามหลังจากรัศมี 9.2 เป็น 10.8 หน่วย สิ้นสุดที่ 1.22 วินาที เทียบ Lv50 ที่ 0.98 วินาที เพดาน Low40/High96 และ pool160 คงเดิม รูปทรงหลักและคลื่นท้ายถูกจัดลำดับก่อนดาว/เศษพลังตกแต่ง เพื่อให้ Low และการร่ายทับยังรักษาองค์ประกอบสำคัญ

ตรวจภาพรอบแรกพบกรอบตาเล็ง Hunter Focus จมพื้นส่วนล่าง จึงยกขึ้นเป็น 3 หน่วย เพิ่มชั้นกรอบมะกอก/ทองและลูกศรทองเด่นขึ้น ตรวจใหม่บน runtime รอบสุดท้ายพร้อม regression ที่ยืนยันกรอบตาครบและอยู่เหนือพื้น งานภาพเป็น mesh/material procedural ต้นฉบับ ไม่มี asset ภายนอกเพิ่ม

การเปิดคลิป gameplay พบ lifecycle เดิมล้าง sequence เมื่อผู้ร่ายเสีย HP แม้ Simulation ยังร่ายต่อ ทำให้ Moonbeam ที่โดนโจมตีระหว่างร่ายไม่แสดงภาพออกผล แก้ world.ts ให้ความเสียหายไม่ล้างภาพสกิล การตาย เปลี่ยนอาชีพ และ cast cancellation จริงยังล้างตามเดิม พร้อมตรวจภาพออกผลจริงของทุกสกิลด้วย lv60Cue และ skillMotion ไม่ใช้เพียงค่า MP/kill เป็นหลักฐานภาพ Moonbeam บันทึก HP ลดระหว่าง cast และยังเห็น release ครบ

ตรวจรับ runtime รอบสุดท้าย: build ผ่านและ 55 checks ผ่าน (46 code/authority/timing/pool, 9 browser) เปรียบเทียบ 96 เฟรมและตรวจ motion sheets จากคลิปจริงทั้งหก ยืนยัน release cue/motion ของแต่ละสกิลและ active กลับเป็นศูนย์ ไม่มี model/page error อนุมัติขอบเขต VFX Lv60 สำหรับเผยแพร่และผู้เล่นตรวจต่อ ไม่รับรองคะแนนภาพทั้งเกมหรือ FPS เครื่องจริง ข้อมูลเครื่องและ performance อยู่ใน REVIEW.md และ validation.json
