# Passive EXP test item

The next signed-in connection of a server-verified `ADMIN_EMAIL` account receives **one EXP Charm** once. Click it in Bag to equip the first empty auxiliary slot, drag it to any of the four auxiliary slots (keys 7–0), or select it in Skills. While slotted and owned, gameplay EXP is multiplied by **9999**. Unequipping removes the bonus immediately. Clicking its hotbar slot or pressing its key does not activate or consume it. Multiple copies or duplicate saved slots never stack the multiplier. Six skill slots reject it.

The server derives the multiplier from its own saved inventory and loadout, not client bonus values. Monster and quest rewards use it; each party recipient uses their own charm and gear EXP bonus exactly once. Level 100 remains the cap. Potion slots retain their shared two-second cooldown; the charm displays no potion cooldown.

The optional realm JSON `Player.expTestGrant` marker is now version 2 with count 1. A version 1 marker does not block the corrected grant. Existing EXP Tome inventory is preserved because legitimate and previous test stock cannot be distinguished; no further bulk Tome grants occur. Legacy Tomes still give their fixed 1,000 EXP, unaffected by the charm. Existing progress and save schema remain compatible. A full bag defers the grant until reconnect with room. Realm revision commits make grant, marker, and ledger atomic and safe under retries; no D1 schema migration is required.
