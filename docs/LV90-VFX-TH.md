# VFX Lv90

ออกแบบจากไอคอน v4 จริงและคำอธิบายครบหก เทียบ Lv80 ด้วยกล้องเดียวกันทั้ง Low/High เพิ่มความยิ่งใหญ่ด้วยรูปทรงเฉพาะสกิลและคลื่นปิดท้าย โดยรัศมีตกแต่งไม่เปลี่ยนรัศมีดาเมจ

คงแรงสั่น Lv90 ที่ 0.075 หน่วยโลก / 0.30 วินาที ลดแรงตามเวลาและกลับศูนย์ พร้อมรองรับ Reduce Motion ใช้กติกา MP/damage/DOT/slow/cooldown เวลา cast/recovery สามเท่า เซฟ และ server authority เดิม รวมถึงการเคลื่อนไหว Lv50–70 ที่ตรวจรับแล้ว

หลักฐานแยก render-only preview ออกจากการเรียนและร่าย rank1 ผ่าน UI จริง ค่าประสิทธิภาพจาก Chromium ANGLE SwiftShader เป็นการเปรียบเทียบใน software renderer ไม่ใช่ FPS เครื่องผู้เล่น


| ภาพตกแต่ง | Lv80 baseline | Lv90 |
| --- | ---: | ---: |
| ระยะรูปทรงหลัก | 1.16 วินาที | 1.38 วินาที |
| รัศมีคลื่น | 14.4 | 15.6 |
| คลื่นปิดท้าย | 3 จังหวะ | 4 จังหวะ |
| จบเอฟเฟกต์ | 1.86 วินาที | 2.12 วินาที |

Low จำกัด 40 ชิ้น High 96 และ pool 160 ใช้ geometry และ material ร่วม รูปทรงหลักและคลื่นทั้งหมดจองก่อนรายละเอียดรอบนอก Low จึงยังมีดาบ โล่ ดาว ราก ลูกศรแดง และเขี้ยวงูครบ ไม่มี sprite หรือ texture ใหม่ รัศมีตารางเป็นงานภาพเท่านั้น


ตรวจรับ build สุดท้าย: build ผ่าน, code/regression 57 รายการ และ browser 10 รายการ รวม 67 รายการ ภาพเทียบ Low/High 96 เฟรม การเรียน/ร่ายจริงครบหก และ Reduce Motion Lv90 อีกหนึ่งครั้ง ไม่มี page/model error ทุกสกิลมี MP ลด cooldown เริ่ม kill เพิ่ม และกลับไม่มี motion/VFX ค้าง แรงสั่นจริงทั้งหกมี amplitude 0.075 และคืนศูนย์ ส่วน Reduce Motion ไม่มี shake

ผู้ควบคุมเปิดภาพทั้งหก Low/High ภาพเทียบ Lv80 เฟรม crescendo 1.2 วินาที และภาพเรียงตามเวลาจากคลิป preview ทั้งสามกับคลิปร่ายจริงทั้งหกแล้ว อนุมัติงาน Lv90: ดาบปักพื้นกับหินทรงแหลม, โล่ด้านข้างกับคลื่นกระแทก, ดาวทองห้าแฉกและแสงตก, รากไม้เกี่ยวรั้งพร้อมเถาทอง, ลูกศรแดงพร้อมคมต่ำ และหัวงูพิษปากเปิดมีเขี้ยวชัด คลื่นสี่จังหวะขยายต่อเนื่องและจางหาย โดยรูปทรงหลักยังครบใน Low สรุปนี้ไม่ใช่คะแนนงานภาพทั้งเกมหรือ FPS เครื่องผู้เล่น

ชุดทดสอบ pool เดิมปรับชื่อรูปทรง Earthbreaker จาก slab เป็น stoneshard ตามหินทรงแหลมใหม่ ยังคงตรวจว่ารูปทรงหลักเกิดจริงแม้ pool เต็มและจำนวน allocation ไม่เกิน 160 ส่วนกติกาและ runtime อื่นไม่มีการแก้ในรอบนี้
