# Monster balance v2 and equipment presentation

Source: user-uploaded `monsters-v.2.csv`, retained verbatim at `docs/balance/imported/monsters-v2.csv`. Runtime values are in `src/config/content.json` → `normalBalance.checkpoints`: 19 rows, Lv5–95, at intervals of 5. HP, ATK, DEF, gold and independent material/refine-stone percentages follow the CSV exactly, including alternating HP increases/decreases. Shade essence rare at Lv60/65 lacks a percent sign; values 1.5/1.65 are interpreted as 1.5%/1.65%. Levels above the final checkpoint use Lv95 values; therefore Lv100 elites use that base until a Lv100 row is supplied. Boss/mini multipliers and level-based gold remain unchanged. Existing administrator species overrides still take precedence.

Monster balance revision 5 preserves living monsters' HP fractions from revision 4, dead-monster respawn timers and player progress. Revision 4 HP values are retained solely for migration. Universal-weapon migration is described in `UNIVERSAL-WEAPONS.md`; both frontend and Railway server must run this release.

Five pants icons were generated using OpenAI image generation for Thornwood, Suncrest, Moonveil, Frostguard and Starfall. Their transparent PNGs live in `public/icons/<set>-pants.png`, each 256×256 with a 200-pixel-tall object and matching top/bottom padding. Icons have distinct leaf, sun, moon, frost and star designs. Existing sword/staff/bow icon assets are reused for class-specific weapon presentation.

Validation: frontend and realtime builds; 50 focused balance/equipment/material/migration tests and 3 inventory browser tests. Browser QA uses headless Chromium with SwiftShader at 1200×800 and mobile 390×844; this verifies behavior/layout rather than player-device FPS. Local browser fixture retains the same equipped weapon UUID/refinement when switching three classes and checks all five distinct pants and eight shared weapon recipes, with no page errors.
