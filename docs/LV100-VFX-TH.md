# VFX Lv100 ขั้นสุดท้าย

ออกแบบจากไอคอน v4 จริงและ description ครบหก ใช้ Lv90 เป็นฐาน เพิ่มความเด่นของรูปทรงหลักและจังหวะ crescendo ให้เป็นสกิลขั้นสุดท้าย โดยขนาดภาพไม่เปลี่ยนรัศมีดาเมจ

คงแรงสั่นสูงสุด Lv100 ที่ 0.110 หน่วยโลก / 0.36 วินาที ลดแรงแล้วคืนศูนย์ พร้อม Reduce Motion และกติกา damage/slow/MP/cooldown/DOT เวลา cast/recovery สามเท่า เซฟ/server authority เดิม รวมถึงการเคลื่อนไหว Lv50–70 ที่ตรวจรับแล้ว

เปรียบเทียบ Low/High กับ Lv90 ด้วยกล้องเดียวกัน แยก render-only preview ออกจากการเรียนและร่าย rank1 ผ่าน UI จริง ค่าประสิทธิภาพจาก Chromium ANGLE SwiftShader เป็น software renderer ไม่ใช่ FPS เครื่องผู้เล่น

| รายการ | Lv90 | Lv100 |
| --- | --- | --- |
| ช่วงรูปทรงหลัก | 1.38 วินาที | 1.90 วินาที |
| รัศมีตกแต่งสูงสุด | 15.6 | 17.4 |
| คลื่นปิดฉาก | 4 | 5 |
| เวลาปิดฉากทั้งหมด | 2.12 วินาที | 2.65 วินาที |

- Meteor Blade: คมดาบเพลิงแดง–ส้มซ้อนหน้าคมขาวทองขนาดใหญ่ กวาดหลายชั้นและคมปิดฉาก
- Guardian Quake: ดาบทองปักพื้น หินเหลี่ยมแตกยกตัวและเสาแสงระเบิด ไม่เปลี่ยนเป็นสกิลบัฟ
- Astral Storm: แขนกาแล็กซีม่วง–ชมพูหมุนกว้าง ดาวขาวและจังหวะยุบตัว
- Worldtree Bloom Burst: ต้นไม้ทองเรือนยอดกว้าง ดอกชมพู ใบเขียว และรังสีระเบิดออกจากเป้าหมาย ไม่เปลี่ยนเป็นฮีล
- Sky Barrage: ลูกศรฟ้ายิงขึ้นแล้วพุ่งลงพร้อมแนวแสงและปีกขาว
- Wild Hunt Strike: กวางเขาทองขนาดใหญ่และแนวลูกศรทองแผ่ออกจากเป้าหมาย

รูปทรงหลักและคลื่นสุดท้ายถูกจองก่อนรายละเอียดเสริม Low ไม่เกิน 40 effects / High ไม่เกิน 96 และ pool ไม่เกิน 160 meshes ใช้ geometry 3D พร้อมวัสดุแรเงา ไม่มี texture หรือ billboard

ตรวจรับ source สุดท้ายหลังเจ้าของ runtime หยุดแก้: production build ผ่าน, code 59 รายการ + browser 10 รายการ = 69 รายการผ่าน เก็บภาพเปรียบเทียบ 96 เฟรม และร่ายสกิลที่เรียน rank1 จริงครบหกในโหมด practice ผ่าน UI ตรวจ MP ลด, cooldown เริ่ม, kill เพิ่ม, โดนมอนสเตอร์โจมตีระหว่าง cast, VFX เคลียร์ และกล้องคืนศูนย์ พร้อมกรณี Reduce Motion ไม่สั่น ไม่พบ page/model errors

ผู้ควบคุมเปิดภาพ Low/High, comparison ทั้งสามอาชีพ, ลำดับเฟรมจากวิดีโอ preview และวิดีโอร่ายจริงครบหกพร้อม Reduce Motion แล้วอนุมัติ VFX เฉพาะรอบนี้ที่ 8.5/10: รูปทรงหลักใหญ่กว่า Lv90 และแยกกันชัด ต้นไม้มีช่อดอก/ใบเต็มเรือนยอด ปีกเป็นขนนกมีปริมาตร เอฟเฟกต์คลี่ออกและคืนฉากครบ คะแนนนี้ไม่ใช่คะแนนรวมทั้งเกม
