# ผสมรูนซ้ำชนิดได้

Convert 4 → 1 รับรูนจริง 4 ชิ้น rarity เดียวกันโดยซ้ำชนิดได้ รวมถึงใช้ชนิดเดียวกันทั้ง 4 อัน ผลลัพธ์เป็นชนิดที่เลือก 1 อัน rarity เดิม เลือกชนิดผลลัพธ์ตรงกับวัตถุดิบได้

เซิร์ฟเวอร์ตรวจ ID ที่เป็นเจ้าของและไม่ซ้ำกัน กินเฉพาะชิ้นที่เลือก การส่ง ID ชิ้นเดียวซ้ำหรือใช้รูนคนละ rarity ถูกปฏิเสธโดยไม่เสียของ คำสั่งไคลเอนต์เก่าที่อ้างชนิดซ้ำถูกจับคู่กับชิ้นจริงที่ยังไม่ได้เลือก ไม่เปลี่ยนสูตรอัปเกรด 2 → 1 หรือกติกาฝังสองช่อง

Build ผ่าน ทดสอบ 31 รายการ: กติกา/authority/drop 28, browser 3 ตรวจบนคอมและมือถือ ทั้ง 4 ชิ้นชนิดเดียวและสองคู่ต่างชนิด รวม flow ออนไลน์ที่ส่ง payload ผ่าน API fixture เข้า realm.transact จริงและแสดงผลตอบกลับจากเซิร์ฟเวอร์ ภาพอยู่ใน artifacts/rune-convert-repeat ใช้ Chromium/SwiftShader ตรวจความถูกต้องและการจัดวาง ไม่อ้างผล FPS เครื่องผู้เล่น
